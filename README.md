# Capital Dry Cleaning website

Single-page site for Capital Dry Cleaning, 11 The Centre, High Street, Halstead.

Live at https://capitaldrycleaning.co.uk (hosted on Netlify, DNS via 123-reg).

- `index.html` – the whole site (styles, illustrations and script are all in this one file)
- `images/` – drop real photos here using the filenames in `images/README.txt`; the page picks them up automatically and falls back to the illustrations for any that are missing

Deployed by Netlify from the `main` branch. Any change pushed to `main` goes live within a minute or so.

## Editing

Everything is plain HTML and CSS in `index.html`. Text is in the obvious places; colours are the variables at the top of the `<style>` block (`--navy`, `--blue`, `--sky` and so on).
